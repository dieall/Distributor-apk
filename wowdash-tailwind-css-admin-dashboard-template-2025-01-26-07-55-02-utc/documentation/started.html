Project Setup
1. Install Node.js on Your System

To use npm (to install Sass), we first have to install Node.js, which we can easily do. Go to the official site and download the related installer (based on the operating system)


2. Initialize NPM

After the installation, you can access the npm command to install the wowdash admin and manage dependencies. The initialization means creating the package.json file where we store our configuration.

Open your terminal, navigate to the worrking-file and run:

npm install

After the initialization, our package.json file will look something like this:

3. Run The project

After the previous steps, all you need is to run our scripts based on all needs.

npm run start

4. The Project Upload in cPanel

Login in your cpanel. Then go to dist folder and zip the folder and upload (normally public_html)
